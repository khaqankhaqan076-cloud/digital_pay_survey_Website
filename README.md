# Digital Pay Survey — Student Digital Payment Habits

A web-based data collection project designed to collect information about **digital payment habits and financial behavior among students**.

This project was developed as part of a **Data Analysis project**, where the collected survey responses can later be cleaned, analyzed, visualized, and used to generate meaningful insights.

## 📌 Project Overview

Digital payment methods such as Easypaisa, JazzCash, bank mobile applications, debit/credit cards, Raast, and other online payment platforms are becoming increasingly common among students.

The purpose of this survey is to collect structured data about:

* Digital payment usage
* Preferred payment methods
* Payment frequency
* Digital spending behavior
* Financial management habits
* Security and privacy concerns
* Trust in digital payment systems
* Problems experienced during digital transactions
* Overall satisfaction
* Future adoption of digital payments

The collected data can be used for educational and analytical purposes.

## 🎯 Project Objectives

The main objectives of this project are:

1. Collect primary data from students.
2. Understand how students use digital payment methods.
3. Analyze students' digital spending behavior.
4. Identify common problems with digital payments.
5. Study security and trust perceptions.
6. Examine financial management behavior.
7. Prepare the collected data for further analysis.
8. Create meaningful insights and visualizations from the survey data.

## 🔗 Data Collection

The website is connected to **Google Sheets through Google Apps Script**.

When a participant submits the survey:

1. The website collects the responses.
2. The responses are converted into a data payload.
3. The data is sent to the Google Apps Script Web App.
4. Google Apps Script processes the submitted information.
5. The responses are stored in Google Sheets.
6. The collected dataset can then be exported for analysis.

This allows the website to work as a simple **online primary data collection system**.
